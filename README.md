# 双世界 MMO

工作室：云锦繁星。

Unity 客户端加六个 .NET 进程的 2.5D 双世界 MMO。P0 原型已收口：五个职业各一组技能带蓝条，真机上能换职业、能走位施法，Boss 分两个阶段按血线切换并出手打人。现在进 P1，第一行是账号登录：口令换会话令牌。

## 当前做到哪

**P1-1a1 完成**（v1.59，2026-11-09）：口令换成会话令牌。

- 「角色」schema 里的账号表只存 PBKDF2-HMAC-SHA256 哈希和每行随机盐，不存明文。
- 网关 `POST /login`：正确口令回 200 带 32 字节随机令牌（进程内存、带 TTL），错误口令 401；不存在的账号与错误口令同响应同耗时，空账号空口令 400。
- 库凭据只从环境或 `/srv/mmo/gamedb.env` 读，缺凭据时进程照常起、登录回 503。
- 笔记本上 26 项全过（本机静态段 9 项）；e7、e8 回归全过。

**下一张**：P1-1a2，网关只认令牌——没有令牌或令牌过期的连接不能再发技能。
