# 双世界 MMO

工作室：云锦繁星。

Unity 客户端加六个 .NET 进程的 2.5D 双世界 MMO。P0 原型已收口：五个职业各一组技能带蓝条，真机上能换职业、能走位施法，Boss 分两个阶段按血线切换并出手打人。P1 从账号起：口令换令牌，战斗长连接只从网关进、网关只认令牌，建角色与进本走网关到角色服的 gRPC，深渊按人数扣疲劳、一天到 6000 封顶，温泉只把疲劳加回 1500，巢穴一周 12 个单人份、怪物按进本人数缩放，等级经验走同一笔结算、两人同场多一截少量加成。

## 当前做到哪

**P1-2d 完成**（v1.70，2026-11-09）：组队少量经验，P1-2 收口。笔记本上 35 项全过。

- 等级经验只走同一笔：`config/exp.json` 是唯一数值正本（`level_cap: 100` 是方案写定，基础经验、组队加成幅度、每级所需经验方案没写定，暂取 120 / 10% / 1000 并注明待定）。角色服 `ExpSettlementRepository` 用 `for update` + 事务号幂等，只写 `level` / `exp`；改配置重启即生效，代码里没有第二套数字。
- 单人 120、两人同场 132，3、4 人仍是同一截 132（不按人数叠加）；只加经验，疲劳、周份额、货币、背包、进本记录前后不变。等级到 100 停住，库层 `CHECK` 仍是最后一道闸。
- 活动、副本、任务、竞技场、战场、城战和世界 Boss 都调同一个 `SettleExp` 接口，请求里没有经验数值，改包改不了加成；战斗服通关时按本场人数给每个成员各记一笔，没配上游就只写 P0 本地结算记录，练习场与 P0 老核对行为不变。
- 笔记本 P1 十张卡、Mac E/P0 九张卡全部回归通过（p1-2c 一次偶发 holder 时序竞态，单独复跑 52/52）。**真机段仍未跑成**：`adb devices` 为空、没有已授权设备，不是用例失败；证据沿用 P1-2b1 的 59/59，等设备连上再补。

## 最近几次

**v1.70** 组队少量经验：等级经验同一笔结算、两人同场多一截、伤害和掉落不变、等级封顶 100。

**v1.69** 巢穴：每周 12 个单人份、按人数倍增产出、怪物生命与伤害按人数缩放。

**v1.68** 温泉：只恢复 1500 疲劳，只补疲劳、不越界、整笔事务。

**v1.67** 深渊疲劳：人数倍增、日上限 6000、跨天归零、整笔事务。

**v1.66** 主线单人进本：副本表、战斗服人数上限与 EnterRejected、角色服进本校验与记录。

**v1.65** 发奖事务：事务号主键、整笔一个事务、并发只有一笔成功。

**v1.64** 货币增减：币种表、原子加减、余额不足拒绝。

**v1.63** 背包与绑定：背包表、物品表与绑定规则、`CanTrade` 判定。

**v1.62** 等级封顶 100：`SetLevel`、账号条件、库层 CHECK。

**v1.61** 创建角色：角色表、四种出身与十条分支的配置、网关到角色服的第一个 gRPC。

**v1.60** 网关只认令牌：`/battle` 入口、令牌握手、逐帧判到期、字节流转发。

**v1.59** 口令换会话令牌：账号表、登录接口、令牌与口令哈希。

**v1.58** 五职业、蓝条、仇恨、复活，Boss 两阶段；方案删掉「随机副本」，「英灵图鉴」保留。
