# 双世界 MMO

工作室：云锦繁星。

Unity 客户端加六个 .NET 进程的 2.5D 双世界 MMO。当前在 P0 原型阶段：五个职业各一组技能带蓝条，真机上能换职业、能走位施法，Boss 分两个阶段按血线切换并出手打人。

## 当前做到哪

**P0-3 完成**（v1.58，2026-11-09）：五职业、蓝条、仇恨、复活、Boss 两阶段，一路做到真机。

- 坦克、战士、法师、射手、牧师各一组主动技能加普攻，全在 `config/classes.json` 与 `config/skills.json`。战士读力量、射手读敏捷、法牧读精神；体力是所有人的生命，坦克的仇恨稳定读体力、体力不进攻击。
- 蓝上限 = 职业基础 + 精神 × 系数，蓝不进伤害，不够就拒。
- 牧师能拉起同场倒地的队友，不能拉自己；被拉者等级不变，只扣当前等级已有经验的 10%，经验为零不扣。
- Boss 两个阶段走配置，血线到了广播 `BossPhase`，换阶段就换出手参数，打有效仇恨最高的活人。
- 真机上换职业按钮循环五个职业，蓝条、职业名、阶段名、技能名都跟着服务端走。核对：3a 17 项、3b 9 项、3c 真机 59 项，全过。
