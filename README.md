# 双世界 MMO

工作室：云锦繁星。

Unity 客户端加六个 .NET 进程的 2.5D 双世界 MMO。P0 原型已收口：五个职业各一组技能带蓝条，真机上能换职业、能走位施法，Boss 分两个阶段按血线切换并出手打人。P1 从账号起：口令换令牌，战斗长连接只从网关进、网关只认令牌。

## 当前做到哪

**P1-1a2 完成**（v1.60，2026-11-09）：网关只认令牌。

- 战斗长连接只从网关进：网关开 `/battle`，握手先认令牌，认不过直接 401。
- 认过才连战斗服，之后字节流转发；网关不解析技能、不算伤害。
- 令牌有效期逐帧判，到期就断连接——连上之后也不能一直发。
- 没令牌、伪造令牌、过期令牌都建不起连接。笔记本上 23 项全过；e7、e8、P1-1a1 回归全过。

**下一张**：P1-1b1，创建角色——种族只存外观和出身，职业与分支能写入，主线场次和立仙或立魔为空。
