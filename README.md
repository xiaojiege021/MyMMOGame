# 双世界 MMO

工作室：云锦繁星。

Unity 客户端加六个 .NET 进程的 2.5D 双世界 MMO。P0 原型已收口：五个职业各一组技能带蓝条，真机上能换职业、能走位施法，Boss 分两个阶段按血线切换并出手打人。P1 从账号起：口令换令牌，战斗长连接只从网关进、网关只认令牌，建角色与进本走网关到角色服的 gRPC，深渊按人数扣疲劳、一天到 6000 封顶，温泉只把疲劳加回 1500，巢穴一周 12 个单人份、怪物按进本人数缩放。

## 当前做到哪

**P1-2c 完成**（v1.69，2026-11-09）：巢穴周份额和人数缩放。4 人打一次后这周剩余 8 个单人份，每人拿到 4 份。

- 巢穴 1–4 人、不扣疲劳、只占周份额：一周 12 个单人份，单人能打 12 次，3 次满员的总产出与 12 次单人相同。份额不足整笔拒绝，跨周按数据库周首归零，并发两笔冲上限只有一笔成功。
- `weekly_share` 记「本周已用掉的单人份」，剩余份额与本次产出份数都在进本回包里；请求里带不进数值，角色服是唯一写入方。产出的实物种类属掉落表，本行只把份数记进进本记录。
- 战斗服按 `party_size` 缩放 Boss 生命与伤害（系数在 `config/dungeons.json`，方案没写定曲线暂按人数线性），玩家技能伤害与结算经验不变；不带参数的练习场仍是原来的 900 血。准入只看等级，没加境界门槛。
- 笔记本上 52 项全过；P0、P1-1、P1-2a、P1-2b1、P1-2b2 全部回归通过。真机段这次没有已授权设备（`adb devices` 为空），证据沿用 P1-2b1 的 59/59，等设备连上再补。

**下一张**：P1-2d，组队少量经验——单人没有加成，两人经验更多，伤害和掉落不变，等级停在 100。
