# 双世界 MMO

工作室：云锦繁星。

Unity 客户端加六个 .NET 进程的 2.5D 双世界 MMO。P0 原型已收口：五个职业各一组技能带蓝条，真机上能换职业、能走位施法，Boss 分两个阶段按血线切换并出手打人。P1 从账号起：口令换令牌，战斗长连接只从网关进、网关只认令牌，建角色走网关到角色服的 gRPC。

## 当前做到哪

**P1-1b2 完成**（v1.62，2026-11-09）：等级写入封顶 100。

- 角色服 `SetLevel`：1–100 可写，越界回 `level_out_of_range`，拒绝而不夹到 100。
- 写等级带账号条件，改不到别人的角色；网关 `POST /character/level` 认令牌后转发。
- 库层 `CHECK (level BETWEEN 1 AND 100)` 是最后一道闸，绕过接口直写 101 会被 PostgreSQL 拒掉。笔记本上 26 项全过；P1-1a1、P1-1a2、P1-1b1、e7、e8 回归全过。

**下一张**：P1-1b3，背包与绑定——物品能进格子，绑定物品不能直接交易。
