# 长生隙

双世界 MMO。名字取《梦长生》的「长生」，与外环隙、裂隙实例的「隙」——表里两界之间那道缝。工作室：云锦繁星。上图就是应用图标，源文件在 `client/MMOGame/Assets/Art/Icon/app-icon.png`；Android adaptive 图标的背景用这张插画、前景是全透明的 `app-icon-foreground.png`，换图后跑一次 `Assets/Editor/ApplyAppIcon.cs` 就会把各档槽位重新写一遍。

Unity 客户端加六个 .NET 进程的 2.5D 双世界 MMO。P0 原型已收口：五个职业各一组技能带蓝条，真机上能换职业、能走位施法，Boss 分两个阶段按血线切换并出手打人。P1 从账号起：口令换令牌，战斗长连接只从网关进、网关只认令牌，建角色与进本走网关到角色服的 gRPC，深渊按人数扣疲劳、一天到 6000 封顶，温泉只把疲劳加回 1500，巢穴一周 12 个单人份、怪物按进本人数缩放，等级经验走同一笔结算、两人同场多一截少量加成。P1-3 从表世界起：八块首发地表按方案正文编号，人能进入一条分线，对话只在配置里，地表资源进已有的同一组 Launch AB；同一分线里的人按 5–10Hz 看到彼此的坐标与朝向，周围的人按距离分完整、简模、只留名字三档，档位由世界服给；矿和药能采，产物交给角色服进背包、疲劳不变，灵石矿脉不许个人采；飞行和跨区认境界，没权限的飞请求被拉回地面。P1-4 从强化起：+12 上限分三档材料，失败只掉 1 级、不碎也不清零，概率只在配置里。

## 当前做到哪

**P1-4a 完成**（v1.76，2026-11-10）：强化三档和失败掉 1 级。笔记本连库连服 57 项、Mac 客户端 6 项全过；平板重新出包后真机 P0-3c 59 项全过。

- 方案 9.2 写定最高 +12，+1 到 +6 低级石、+7 到 +9 中级石、+10 到 +12 高级石，低级石不能代替高一级的石；失败只掉 1 级，不碎、不清零、没有失败累计必成。概率与金币 / 石头消耗都没写定：`config/enhance.json` 是唯一数值正本（均注明待定），`EnhanceTable` 加载时逐条校验写定规则，十一类坏配置都起不来，改概率重启即生效，代码里没有第二套数字。
- 角色服是强化等级、背包与货币的唯一写入方：`db/character/enhance.sql` 按「角色 + 格位」存等级、库层 CHECK 0..12；`EnhanceRepository` 在一笔事务里抢事务号、锁装备行、按配置校材料档位、扣石头与金币、服务端掷点、成功 +1 或失败掉 1 级，任何一步不满足整笔回滚。
- `proto/mmo/character.proto` 加 `Enhance`，请求只有 `account / character_id / slot / stone_id / txn_id`；网关 `/character/enhance` 认令牌 + 复核归属，事务号由网关生成，业务拒绝回 200 + `ok=false`。客户端 `Assets/Net/CharacterEnhance.cs` 是纯 .NET 拆装，只按服务端回包展示。
- 连服证据：低级石连点 6 手到 +6，用低级石点 +7 回 `wrong_stone` 且库里状态一格没动；中级 / 高级石点到 +12 后 `at_cap`；把三档概率改成 0 重启，连续三次失败 `+11 → +10 → +9 → +8`，装备还在、没有必成；改回 1 重启再点成功。请求体塞 `level / success_rate / gold / txn_id / account` 全无效。笔记本 P1 十七张老卡、Mac E/P0 与六个客户端段全量回归全过。
