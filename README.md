# 双世界 MMO

工作室：云锦繁星。

Unity 客户端加六个 .NET 进程的 2.5D 双世界 MMO。P0 原型已收口：五个职业各一组技能带蓝条，真机上能换职业、能走位施法，Boss 分两个阶段按血线切换并出手打人。P1 从账号起：口令换令牌，战斗长连接只从网关进、网关只认令牌，建角色与进本走网关到角色服的 gRPC，深渊按人数扣疲劳、一天到 6000 封顶。

## 当前做到哪

**P1-2b1 完成**（v1.67，2026-11-09）：深渊按人数扣疲劳，一天到 6000 不能再进。

- 深渊 1–4 人：单人一次扣 1 倍、4 人进一次每人扣 4 倍；不占周份额。单人连进四次到 6000，第五次被拒（`fatigue_exhausted`），不扣疲劳也不留进本记录。

- 主线进本仍不扣不占；单人一次的基础消耗方案未写定，留在 `config/dungeons.json`，不写死在代码里。
