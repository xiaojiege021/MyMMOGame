# 双世界 MMO

工作室：云锦繁星。

Unity 客户端加六个 .NET 进程的 2.5D 双世界 MMO。P0 原型已收口：五个职业各一组技能带蓝条，真机上能换职业、能走位施法，Boss 分两个阶段按血线切换并出手打人。P1 从账号起：口令换令牌，战斗长连接只从网关进、网关只认令牌，建角色与进本走网关到角色服的 gRPC，深渊按人数扣疲劳、一天到 6000 封顶，温泉只把疲劳加回 1500。

## 当前做到哪

**P1-2b2 完成**（v1.68，2026-11-09）：温泉只恢复 1500，使用后疲劳只加回 1500。

- 疲劳记「今天已经花掉的」：进本加、温泉减。6000 用一次温泉降到 4500，恢复后能再进一次深渊，再打满仍被拒；已用不足 1500 时只减到 0，不会写成负数。
- 恢复量在 `config/dungeons.json` 的 `hot_spring_recovery`，请求里带不进数值；角色服是唯一写入方，网关 `POST /hot-spring` 只鉴权转发。跨天归零、行锁与事务沿用深渊那套口径。
- 只补疲劳：周份额、进本记录、等级、货币、背包前后不变；并发两笔合计只恢复实际花掉的量。方案没写定每天能用几次，本行不加次数限制。
- 笔记本上 46 项全过；P0、P1-1、P1-2a、P1-2b1 全部回归通过。本行没改客户端与战斗服，真机证据沿用 P1-2b1 的 59/59。

**下一张**：P1-2c，巢穴周份额与人数缩放——4 人打一次后，这周剩余 8 个单人份，每人拿到 4 份。
