# 双世界 MMO

工作室：云锦繁星。

Unity 客户端加六个 .NET 进程的 2.5D 双世界 MMO。当前在 P0 原型阶段：一场单人 Boss 战能在真机上点选目标，按住技能播前摇、拖着左半屏走位，服务端回包之后才出伤害。

## 当前做到哪

**P0-2b 完成**（v1.57，2026-11-09）：前摇、走位、回包三件接上了。

- 按住技能先播前摇，前摇里能拖左半屏走位；撤招之后没有迟到的伤害，血量不动。
- 伤害与硬直只认服务端回包，血条显示的是回包里的剩余血量；被拒绝的这次施法停在原地，血不掉。
- 走位服务端夹两层：场地半径夹圆、速度上限夹步长，客户端坐标不采信。
- 编辑器 30 项、真机 48 项全过；e7、e8、P0-1a~1d 回归全过。
