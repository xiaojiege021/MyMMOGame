# 双世界 MMO

工作室：云锦繁星。

Unity 客户端加六个 .NET 进程的 2.5D 双世界 MMO。P0 原型已收口：五个职业各一组技能带蓝条，真机上能换职业、能走位施法，Boss 分两个阶段按血线切换并出手打人。P1 从账号起：口令换令牌，战斗长连接只从网关进、网关只认令牌，建角色与进本走网关到角色服的 gRPC，深渊按人数扣疲劳、一天到 6000 封顶，温泉只把疲劳加回 1500，巢穴一周 12 个单人份、怪物按进本人数缩放，等级经验走同一笔结算、两人同场多一截少量加成。P1-3 从表世界起：八块首发地表按方案正文编号，人能进入一条分线，对话只在配置里，地表资源进已有的同一组 Launch AB。

## 当前做到哪

**P1-3a1 完成**（v1.71，2026-11-09）：分线加载首发地表。笔记本连服 27 项、Mac 客户端 8 项全过。

- `config/world.json` 是编号正本：八块地名、九个开口的人、五个势力都照方案 2.5 到 2.7 原文；`config/region/` 文件名用地名、`config/dialogue/` 文件名用人物编号，十四句定词逐字照抄。相连关系对称、编号对不上或缺一份配置就起不来。
- 世界服从 E3 空壳起成独立 gRPC 进程，`LineRegistry` 是分线唯一写入方、在线状态放进程内存；同一人重复进不占名额，满了才开下一条，离开与换区都释放名额。分线容量与每区上限方案没写定，留在配置并注明待定。
- 网关沿用令牌鉴权与角色服归属复核；请求里带不进分线号、人数或容量。旧天城区与焦原按「第 11 场才开」的配置标记拒绝。
- 八块地表进同一个 Launch 包、同一个 Launch 组，没有第二套打包流程；对白只留在配置里，不写进场景或 AB 资源。Unity 编辑器重打 AB 后 manifest 里八块都在，后期境界仍被拒。
- 笔记本 P1 十二张卡、Mac E/P0 十张卡全部回归通过（p1-2c 一次偶发 holder 时序竞态，单独复跑 52/52）。**真机段仍未跑成**：`adb devices` 为空、没有已授权设备，不是用例失败；这一行改了 AOT 与 Launch AB，等设备连上要重新出包再补 P0-3c 真机。

**下一张**：P1-3a2，5–10Hz 位置同步——周围的人能看到移动。

## 最近几次

**v1.71** 首发地表分线：八块密区按方案编号、对话进配置、地表进同一组 Launch AB。

**v1.70** 组队少量经验：等级经验同一笔结算、两人同场多一截、伤害和掉落不变、等级封顶 100。

**v1.68** 温泉：只恢复 1500 疲劳，只补疲劳、不越界、整笔事务。

**v1.67** 深渊疲劳：人数倍增、日上限 6000、跨天归零、整笔事务。

**v1.64** 货币增减：币种表、原子加减、余额不足拒绝。

**v1.63** 背包与绑定：背包表、物品表与绑定规则、`CanTrade` 判定。

**v1.62** 等级封顶 100：`SetLevel`、账号条件、库层 CHECK。

**v1.61** 创建角色：角色表、四种出身与十条分支的配置、网关到角色服的第一个 gRPC。

**v1.60** 网关只认令牌：`/battle` 入口、令牌握手、逐帧判到期、字节流转发。

**v1.59** 口令换会话令牌：账号表、登录接口、令牌与口令哈希。

**v1.58** 五职业、蓝条、仇恨、复活，Boss 两阶段；方案删掉「随机副本」，「英灵图鉴」保留。

**v1.56** 点选与切换目标，第一次把玩法装进热更程序集和 Launch AB。
