# 长生隙

> 这是一个**学习 / 练手项目**，非商业、不打算上线，仅用于探索 Unity + 多进程权威服的 MMO 技术栈。代码以 MIT 许可开源；游戏世界观与原创文字内容（题字、旧谣等）保留著作权。

双世界 MMO。名字取《梦长生》的「长生」，与外环隙、裂隙实例的「隙」——表里两界之间那道缝。工作室：云锦繁星。上图就是应用图标，源文件在 `client/MMOGame/Assets/Art/Icon/app-icon.png`；Android adaptive 图标的背景用这张插画、前景是全透明的 `app-icon-foreground.png`，换图后跑一次 `Assets/Editor/ApplyAppIcon.cs` 就会把各档槽位重新写一遍。

Unity 客户端加六个 .NET 进程的 2.5D 双世界 MMO。客户端只画服务端确认过的结果，判定全在服务端：角色服是账号、角色、背包、装备、货币、疲劳与次数的唯一写入方，战斗服在本地结算技能与掉落，网关只认令牌并复核归属，世界服管分线与同屏档位，社交服管宗门 / 队伍 / 洞府，全局服管拍卖挂单与赛季。玩法正本见 [MMO系统架构方案](docs/MMO系统架构方案.html)：表里两界与八块首发地表、十一段境界与段内四阶、主线十二场加深渊 / 巢穴 / 高难 / 竞技场 / 战场 / 城战 / 世界 Boss、强化与结晶、宗门与洞府、金币 / 灵石 / 元宝三套货币（拍卖抽的税直接销毁，不进任何背包）。全部可调数值都在 `config/`，改配置重启生效，代码与 proto 里没有第二套数字；热更程序集只用单层泛型容器。逐张卡的交付与核对结果只看 [开发日志](docs/开发日志.md)。
