# 长生隙

> 这是一个 **AI 辅助开发的学习 / 练手项目**，非商业、不打算上线，仅用于探索 Unity + 多进程权威服的 MMO 技术栈。代码以 MIT 许可开源；游戏世界观与原创文字内容（题字、旧谣等）保留著作权。

双世界 MMO。名字取《梦长生》的「长生」，与外环隙、裂隙实例的「隙」——表里两界之间那道缝。工作室：云锦繁星。上图就是应用图标，源文件在 `client/MMOGame/Assets/Art/Icon/app-icon.png`；Android adaptive 图标的背景用这张插画、前景是全透明的 `app-icon-foreground.png`，换图后跑一次 `Assets/Editor/ApplyAppIcon.cs` 就会把各档槽位重新写一遍。

Unity 客户端加六个 .NET 进程的 2.5D 双世界 MMO。P0 原型已收口：五个职业各一组技能带蓝条，真机上能换职业、能走位施法，Boss 分两个阶段按血线切换并出手打人。P1 从账号起：口令换令牌，战斗长连接只从网关进、网关只认令牌，建角色与进本走网关到角色服的 gRPC，深渊按人数扣疲劳、一天到 6000 封顶，温泉只把疲劳加回 1500，巢穴一周 12 个单人份、怪物按进本人数缩放，等级经验走同一笔结算、两人同场多一截少量加成。P1-3 从表世界起：八块首发地表按方案正文编号，人能进入一条分线，对话只在配置里，地表资源进已有的同一组 Launch AB；同一分线里的人按 5–10Hz 看到彼此的坐标与朝向，周围的人按距离分完整、简模、只留名字三档，档位由世界服给；矿和药能采，产物交给角色服进背包、疲劳不变，灵石矿脉不许个人采；飞行和跨区认境界，没权限的飞请求被拉回地面。P1-4 从强化起：+12 上限分三档材料，失败只掉 1 级、不碎也不清零，概率只在配置里；保护券只挡住那一次掉级，不提高成功率，到账即绑、不分来源；强化转移要求来源高于目标、覆盖目标后来源归 +0，绑定规则跟着这笔事务走；能量结晶分攻击、防御、功能三类按部位限定，装上后可拆下带走复用，装上与拆下都不动强化、绑定和金币。P1-5 从经济起：拍卖行只用金币标价，官方抽走的税直接销毁，不进任何角色背包、系统账户，也不生成物品；商城只认方案 12.1 的十八种上架清单，清单外的请求一律拒绝且不扣元宝。
