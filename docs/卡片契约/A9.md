# A9 卡片契约

> 风险标记 **2**（队列标 2，指「持久数据写入与事务边界」）。实际改动面：`character` 的剩余点数被扣减、新增一行四属性加点与一本加点台账、装备判定多读一截属性、战斗服四条属性公式多一个加项；不碰货币、不动背包、不改伤害公式的分段与乘区。
> 玩法正本：方案 8.2（`docs/MMO系统架构方案.html` `#s7` 成长双轨）的四属性表——力量进战士攻击、敏捷进射手攻击、精神进蓝量与法牧、体力是所有人的生命且坦克仇恨；开发架构 14.6 第 16 行写定「点数只加四属性；装备门槛读加点；不做免费洗点」。上限与洗点方案都没写数字，按开卡默认进配置并标 `pending=true`。
> 开卡确认的口径（用户 2026-11-25 回「按默认执行」）：四属性、单属性上限默认 0 = 不限（只受手上点数约束）、不做免费洗点（`free_respec` 必须 false）、装备门槛按「职业基础 + 已加点」判、竞技场模板属性不动。

| 项 | 默认 | 解除条件 |
