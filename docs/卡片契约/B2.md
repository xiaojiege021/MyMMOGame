# B2 卡片契约

> 风险标记 **4**（跨进程数值口径）。派工时按实际改动面复核：本卡**没有 DB 迁移**、不改钱的写入口，队列原标 `1/2` 不成立；实际碰的是第 4 类——角色服算出 `EquipAttack`（含套装加成），战斗服只读这份快照。依据 [开发架构](../开发架构.md) 14.10 / 14.11 与 [不可逆点清单](../不可逆点清单.md)。
> 玩法正本：方案 `#s8` 装备体系第 1 层——白 → 绿（精良）→ 蓝 → 紫 → 橙 → 红，每档 3–4 套，同品阶装备通用，**穿戴仍看等级和职业**，换装不继承、自然换代；砍掉的是龙珠、天书、重铸、精铸、纹章。核对表默认值表：每档 3 套，**套装只加基础属性**。
> 开卡确认（用户 2026-11-22 选「54 件」）：六档 × 每档 3 套 × 每套 3 件（武器 / 衣服 / 饰品），三套按力道（长刀）/ 法道（法杖）/ 巧道（弓）分；其余 5 种兵器（长枪 / 重锤 / 斧 / 法剑 / 弩）的同档套装武器记内容欠项，归 B15。
