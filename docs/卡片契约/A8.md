## 口径收敛说明

开卡提醒里写的是「新开 `config/attr_points.json`」。落地改成写进 `realms.json` 的 `sub_phases.by_realm[*].grand_points`：这段点数就是**段内阶的属性**，放在同一段配置里可以省掉一份新配置、一个加载器、三个 CLI flag 与 `CharacterConfig` / `TableLoad` / `BootReport` 三处接线（约 300 行固定产物，正好撞 10.1「业务代码 < 固定产物」那条），也不会出现「两份境界配置各写一套」的第二个正本。值本身、默认值、pending 口径与开卡默认一致。
