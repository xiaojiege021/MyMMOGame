# B4 卡片契约

> 风险标记 **2**（队列标 2；实际碰第 1 类「DB 迁移」与第 2 类「协议变更」两处不可逆点，见 [不可逆点清单](../不可逆点清单.md)）。派工前复核：本卡**加一条 character 迁移**（v34）、**改 proto 两处**（ListInventoryResponse 追加字段 + 四条新 rpc），两者都要单独出包、真机欠项累加。
> 玩法正本：方案 `#s8` 第 9.4 节「丹药、坐骑、灵兽与副职」——**玩法坐骑分普通和高级，只差移动速度；商城坐骑只换外观，不叠加速度，不进战斗**；**灵兽（普通 / 高级 / 神兽）只做收集、外观和生活协助，不进入伤害公式**。方案 `#s11` 12.1：坐骑外观是纯外观，玩法坐骑的速度差不在商城。
> 开卡确认（用户 2026-11-24 回「按默认」）：普通 / 高级两档各 2 只占位；速度差按 bps 走配置、代码不写死；只抬世界服地表移动上限（基线仍 `world.json` 的 `max_move_speed`），不进战斗、不影响飞行；灵兽三档各 2 只，收集 = 背包持有（与外观收藏同一口径），生活协助沿用图鉴的 `life_assist` 并与图鉴共用 `hero_codex.json` 那一处总上限；坐骑 / 灵兽从副本掉落产出，商城不卖；客户端坐骑栏与灵兽图鉴屏不做，走 U 线欠项。
