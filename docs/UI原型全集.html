状态与错误口径

  • 登录：POST /login 收 account / password，回 token / expires_in_s；400 请求为空、401 统一「账号或口令不对」（不区分账号不存在/停用/口令错，避免枚举）、503 暂时连不上、网络不可达。
  • 业务拒绝一律 HTTP 200 + ok=false，并带 reason；未生效数值字段必须是 0，不能拿上一次的值展示。
  • 网关认令牌；invalid_token / token_expired 回登录，不弹「口令错」。
  • 载入进度只作表现，能否进世界以服务端回包为准。
  • 不做动作预测、不回传伤害数字、不发权威判定；动画只按 foreswing_ms 拉伸播放。

与第 17 节的关系 / 落地顺序

这套界面属于 17.3「界面与 HUD 皮肤、技能与职业图标」，纯表现层，可以整批后置或整批替换。落地前先守住 17.2 的四份契约：逻辑碰撞体与锚点分离、骨骼与换装挂点、文件名即 AB 地址、动画只作表现。

替换按 17.4 灰度：先一个副本或一块地表 → 真机 P0-3c 59 项 → check-all.sh --card 依赖闭包 → 再铺开 → 里程碑跑 --full。换装挂点清单必须在 P1-5 开工前定死，否则商城外观发货的角色库 schema 与发奖事务要返工。

页面左侧目录、顶部演示返回码、标注开关都是原型工具，不进客户端。

文件关系：docs/登录界面原型.html 是 A01–A03 三屏的详细规格与切图分层说明；本文件是全项目 30 屏的可切换总览。两者共用同一套色板与背景分层，不冲突。本稿为设计稿，不算实施变更，不新增任务卡、不改第 14 节行序。
