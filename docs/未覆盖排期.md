### 2.1 效果层范围（Q1 写设计，Q2 实现）

| 层 | 要有的键 | 说明 |
| --- | --- | --- |
| 7 类效果 | `kind`：buff / debuff / control / hot / dot / shield / cleanse | 每类至少一条样例；`dot` 必须有 `tick_ms` 与每跳 `modifiers` |
| 控制子类型 | `control`：root / slow / stun / silence | 方案只写了定身、减速；v1.184 起 stun 补一条 `cc_stun_1` 样例，silence 仍只留键，具体技能等 B15 内容 |
| 持续时间 | `duration_ms` / `tick_ms` / `max_stacks` / `stack_rule` | 叠层、刷新、独立计时三选一；不写代码里的隐含规则 |
| 驱散 / 免疫 | `dispel_tags` / `immunity_tags` | 触发技与免疫技按标签判定，不按技能编号写死 |
| 交互规则 | 打断 / 硬直 / CC 递减 / 净化 | 打断：前摇中被打断后冷却与资源怎么退；硬直：每技能一条，来自回包；CC 递减：同类控制第 2 / 3 次时长按配置曲线；净化：按标签移除，不按来源 |
| 伤害四段 | 基础攻击 → 强化 → 技能 → 最终 | 与方案 7.2 一致：克制在技能段，防御减免在最终段；**v1.184 起穿透 / 抗性打开**（默认 0，来源等 B10 / B15），四段骨架不变 |
| 边界 | PVE 全额 / 竞技场模板 / 战场 1.3 / 城战科技 | 每层只允许改「最终伤害」之前的乘区，不许改模板属性 |
| 客户端 | buff 条 / 战斗日志 | 只显示回包事实（类型、剩余、层数、来源）；不本地推算剩余时间 |
| 持久化 | 服务端时钟 / 重连 / 死亡清空 | 一场结束、死亡、结算、掉线超时都清；重连窗口内由 Q9 恢复 |

> **v1.184 调整**：穿透 / 抗性由 v1.156 的「可选、默认关闭」改为**打开**——结构接进第 4 段，默认值 0、来源等 B10 / B15；同时补 `cc_stun_1` 样例。四段骨架不变，默认值下与方案 7.2 逐字等价。

> 方案 7.2 原文是四段式，`克制` 在技能段、`防御减免` 在最终段；旧 Q1 把顺序写成「攻击 → 防御 → 暴击 → 克制 → 随机」，本版改正。四段都是乘区，顺序不影响乘法结果，但取整、加减区、百分比叠加一上来就会差，所以按方案写死。
