实现规格

这一套是给 Unity 客户端对照实现的视觉稿，不是正式美术资源。背景用代码绘制，方便按层切图；所有文案与字段取自仓库正本，没有引入方案里不存在的入口。

接口映射（照抄 LoginApi.cs）

请求POST /login
入参account / password
成功200 token / expires_in_s
400请求没发出去，重试一次
401账号或口令不对（不区分是哪个）
503暂时连不上，稍后再试
网络失败连不上网关

状态清单

  • 空账号或空口令：按钮禁用，不发请求（对应 400 的前端拦截）
  • 输入中 / 聚焦：下边框转青，提示清空
  • 提交中：按钮置灰并显示「正在校验」，防重复点
  • 失败：卡片内一行提示，输入框保留，不清口令
  • 成功：存令牌后进创角；创角未选出身/职业/名字时「入世」禁用
  • 载入：进度只作表现，能否进世界以服务端回包为准

背景切图分层

  • 第 1 层 夜空 + 光晕（可纯色 + 一张软光晕）
  • 第 2 层 青白光柱（带透明通道，可轻微呼吸）
  • 第 3 层 远山 / 第 4 层 中山（各一张，静态）
  • 云海：一条横向循环飘动的半透明带
  • 第 5 层 近崖 + 楼阁 + 修士剪影（一张，含暖黄窗光）
  • 暗角与纸纹用全屏叠加，不切图

刻意不做（方案与网关都没有）

  • 记住口令、自动登录、第三方登录、游客登录
  • 选服 / 分线选择（分线由世界服给）
  • 忘记口令、注册账号（账号表由服务端 seed）
  • 公告位、活动弹窗、捏脸、性别、模型预览
  • 创角页列分支（15 级一转才选）
  • 任何写死的概率、次数、TTL 数值
